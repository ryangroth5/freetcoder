Write a Codility-style task.

- Frame it as a small real-world scenario (rivers, tapes, stones, sequences of
  events), then reduce cleanly to an algorithmic core.
- State an explicit expected complexity in `complexity_target`, e.g.
  "O(N) time, O(1) space" -- Codility grades performance separately, and this
  target is enforced by execution.
- Because performance is graded, the hidden cases MUST include inputs at the top
  of the stated bounds, large enough that a quadratic solution cannot finish.
  Your `brute_force_py` must be the naive version that fails them.
- Use N for the primary input size in both prose and constraints.
- Do NOT include a hint.
